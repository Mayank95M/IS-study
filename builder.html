Snapshot builder

Copies the six method pages from ReMeDe, splits each into the 18 elements of the information structure, and saves them as methods.js. Publish that file next to index.html: every participant then sees exactly this text, and the snapshot can be archived with the preregistration.

2. Check the elements

Every cell should be green. A red cell means that element was not found on the ReMeDe page; fix the page in ReMeDe (or the heading's spelling) and fetch again, because a missing element would be missing for participants too.

3. Preview and save

Preview opens the participant page with this snapshot, in this browser only. When every page reads correctly, download methods.js and replace the file in the study's repository.
